# LAB 2 - Agile Backlog Creation & Sprint Simulation in Jira

This folder contains the pharmacy-system backlog prepared from the Lab 1 requirements, a reusable guide for students using their own Lab 1 scenario, and a reflection worksheet.

## Files

- `Lab2_Personalized_Backlog.md` - three Epics, seven traceable Stories, acceptance criteria, proposed priorities and Story Points, and an 11-point Sprint 1 proposal.
- `Lab2_Reusable_Jira_Manual.md` - step-by-step manual that any student can adapt to their own Lab 1 requirements and use cases.
- `Lab2_Sprint_Reflection_Worksheet.md` - reflection template for the four handout questions.
- `Lab2_Stories.csv` - structured issue list to help with Jira entry/import. Jira CSV field mapping can vary by project configuration.

## Jira execution status

The backlog and written materials are prepared. The connected Jira workspace currently has an existing Scrum project for a different application (Personalized News Emailer) and a generic Kanban project.
