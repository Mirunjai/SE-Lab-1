# LAB 2 - Agile Backlog Creation & Sprint Simulation in Jira

This folder contains the editable Markdown and CSV Lab 2 materials derived from the Lab 1 pharmacy inventory requirements.

## Files in this GitHub folder

- `Lab2_Personalized_Backlog.md` - three Epics, seven traceable Stories, acceptance criteria, priorities, proposed Story Points and two proposed sprint scopes.
- `Lab2_Reusable_Jira_Manual.md` - detailed step-by-step manual any student can adapt to their own Lab 1 requirements and use cases.
- `Lab2_Sprint_Reflection_Worksheet.md` - reflection template for the four handout questions.
- `Lab2_Stories.csv` - structured issue list to help with Jira entry/import. Jira CSV field mapping can vary by project configuration.

Word and PDF versions of the backlog, manual and reflection worksheet are provided as separate downloadable deliverables in the ChatGPT response.
