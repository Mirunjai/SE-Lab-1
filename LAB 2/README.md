# LAB 2 - Agile Backlog Creation & Sprint Simulation in Jira

This folder contains the pharmacy inventory backlog derived from the Lab 1 requirements and the brief reflection based on the Jira simulation.

## Files

- `Lab2_Personalized_Backlog.md` - three Epics, seven traceable Stories, acceptance criteria, priorities and proposed sprint scopes.
- `Lab2_Reflection.md` - brief answers to all four reflection questions, using the Jira status outcomes and identifying evidence still missing.
- `Lab2_Stories.csv` - structured Story/issue data.
- `Screenshots/` - required Jira screenshot evidence folder and capture checklist.

The reusable manual has been removed from this GitHub folder as requested.
