# Lab 4 - Gameplay video capture

The assignment requires two genuine 10-second gameplay recordings.

## Before video
1. Use the original starter `game.py` from SETAPESU26/36_dinoRun.
2. Install Pygame with `python -m pip install pygame`.
3. Set or create `dino_highscore.txt` with `0`.
4. Start a screen recording, run the original game, press Space and play for 10 seconds until collision.
5. Show the score and unchanged Best value at Game Over.
6. Save as `before.mp4`.

## After video
1. Run the corrected `game.py` in this folder.
2. Reset `dino_highscore.txt` to `0`.
3. Record the dino changing colour in the air, a double jump, and an obstacle clear (counter/popup).
4. Finish a run with a score above zero and show Best updating.
5. Save as `after.mp4`.

Use OBS, Xbox Game Bar, or another screen recorder capturing the actual game window. Add both MP4 files to this folder. Do not use recreated or placeholder footage instead of actual gameplay.
