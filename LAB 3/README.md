# Lab 3 - Pharmacy Inventory Management System

This folder contains the Lab 3 architecture deliverables for the Pharmacy Inventory Management System continued from Lab 1.

## Deliverables
- `Component_Diagram.pdf` - UML component diagram using a layered architecture.
- `Architecture_Justification.docx` - one-page written justification.
- `Architecture_Justification.pdf` - PDF export of the written justification.

## Model summary
The diagram contains eight components across presentation, application/business, and data layers: Staff Dashboard, Supplier Portal, Inventory & Batch Management, FEFO Stock Allocation, Expiry Monitoring & Alerts, Purchase Order Management, Pharmacy Database, and Reports & Performance Benchmarking.

The interfaces describe stock requests, eligible batch lookup, batch expiry data, replenishment triggers, supplier access to dispatched purchase orders, database access, and reporting data. The diagram uses provided-interface balls and required-interface sockets, with solid connectors and directional arrows.

The design continues the Pharmacy Inventory Management System from Lab 1 and uses its requirements for batch/expiry tracking, FEFO stock selection, replenishment/purchase orders, supplier order access, and performance/availability goals.

The personal Lab 3 manual is provided separately and is intentionally not included in this folder.
